**## Patch Notes — v0.0.10 - M3 Progress — 2026-03-17 ##**

**NPC / Plot Life**
- NPCs now feel much more like real plot inhabitants instead of hidden background workers.
- Starter NPCs now get proper names that are unique to each plot instead of repeating the same names everywhere.
- You can now click NPCs in your owned plot to inspect them.
- Added a new **Character Sheet** panel showing who they are and what they are doing.
- NPC names and activity now appear above their heads in the plot view.

**NPC Readability / Visual Fixes**
- Fixed NPC labels so they stay centered properly above the character.
- Fixed NPC labels so they stay sharp and readable instead of getting blurry.
- Fixed NPC labels so they now follow the visible head/character movement correctly instead of feeling detached.

**World / Interaction Fixes**
- Fixed world plot hover/click issues caused by hidden local plot collision still interfering after leaving your plot.
- Plot interaction in the shared world is now more reliable again.

**Profiles / Ownership**
- Improved old profile-name handling so legacy generic owner names like **Player** can now be corrected on reconnect.

**Technical / Project Quality**
- Continued building on the server-authoritative NPC/order foundation instead of adding throwaway shortcuts.
- M3 now has a much stronger player-readable NPC foundation and is ready for the next step: expanding the order UI beyond the single Scavenge button.
