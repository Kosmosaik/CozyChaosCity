Session wrap-up reference

This file is kept only as a historical note about the kind of materials that are useful at the end of a development session.
It does not define project rules or assistant behavior.

`docs/GPT_Assistant_Rules.md` is the only assistant-instruction document in this repository.

Typical wrap-up materials that have been useful for this project:
- current repo summary based on the actual latest zip/repo state
- recommended git add / commit / push commands
- recommended commit message and next branch name
- current CHANGELOG entry
- updates to active docs under `/docs/`
- a concise handoff summary
- player-facing patch notes
